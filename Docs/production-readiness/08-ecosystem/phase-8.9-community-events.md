# Phase 8.9 — Community, Events and Leaderboards

## Goal
Turn static Join/Remind/leaderboard screens into real community participation systems.

## Implementation
- Define community events, registrations, reminders, attendance, announcements and moderation state.
- Implement join/leave/reminder actions and real attendance evidence where needed for rewards.
- Build leaderboard projections from authoritative XP/achievement data with documented period/ranking rules.
- Add privacy controls for public display names/ranks.
- Add basic moderation/reporting controls for user-generated surfaces before enabling them.

## Tests / Evidence
- Join/remind state persists and respects capacity/time windows.
- Event attendance cannot be self-awarded without defined evidence.
- Leaderboard ranks reproduce from underlying reward data.

## Exit gate
Community actions persist, attendance-based rewards are evidence-backed, and leaderboard values are reproducible.
