## Validation plan

Before navigation implementation, tree-test these tasks with members: train a language,
appeal rejected data, see withdrawable money, enter an event code, find an eligible
deployment, withdraw facial-data consent, and access a newly granted validator queue.

Test separately with validators and leaders because their workspaces use a task-first
model. Target at least 80% correct first destination for the core member tasks and no
material confusion between Wallet, Rewards, and contribution quality.
